# WORKSPACE RULES: SENIOR SOFTWARE ENGINEERING (18 SKILLS SUITE)

## 1. Cổng Điều Phối Nhận Thức: Tư Duy Nhanh & Chậm (System 1 vs System 2)
Mọi input từ User được phân loại tự động bởi `fast-and-slow-thinking`:
- **Hệ Thống 1 (Tư Duy Nhanh - Fast Mode)**: Lệnh chạy, xem log, sửa lỗi nhỏ, commit -> Làm ngay, súc tích qua `Caveman`, tiết kiệm token (< 200 tokens).
- **Hệ Thống 2 (Tư Duy Chậm - Slow Mode)**: Kiến trúc mới, tồn kho, thanh toán, kế toán VAS, debug sự cố -> Bắt buộc qua `Brainstorming` (phản biện A/B) + `Matt Pocock (Grill-Me)` (phỏng vấn bóc tách edge cases) + `TDD` trước khi code.

## 2. Danh Mục 18 Kỹ Năng Kỹ Thuật:
1. **Fast and Slow Thinking**: Bộ điều phối nhận thức System 1 vs System 2, tối ưu token & ROI chất lượng.
2. **Brainstorming**: Tư duy phản biện kiến trúc & phát hiện sản phẩm.
3. **Matt Pocock Skills**: Grill Me (`/grill-me`), Handoff (`/handoff`), Strict TDD (`/tdd`).
4. **Clean Architecture & Refactoring**: 5 nguyên tắc SOLID, diệt trừ code smells, ADR (Architecture Decision Records).
5. **Database Design & Optimization**: Schema, Indexing (B-Tree, Partial), Khóa dòng (`SELECT FOR UPDATE`), diệt N+1 queries.
6. **API Design & Contracts**: Chuẩn REST/JSON-RPC, bảo mật Webhook HMAC-SHA512, Idempotency, RFC 7807, Retry Exponential Backoff.
7. **Systematic Debugging & RCA**: Debug khoa học, Minimal Reproducible Example, 5 Whys, Blameless Post-Mortem.
8. **Superpowers**: Quy trình 5 bước kỹ thuật co-founder (Spec → Plan → TDD → Debug → Verify).
9. **TDD**: Chu trình Red-Green-Refactor, viết test trước khi viết model.
10. **Git Conventions**: Chuẩn Conventional Commits, đặt tên nhánh (`feat/`, `fix/`, `chore/`). Tuyệt đối không commit lên `main`, chia nhỏ Atomic Commits (không dồn commit), SemVer (`18.0.x.x.x`).
11. **UI/UX Pro Max**: Design tokens chuẩn, typography cao cấp, không AI-slop.
12. **Web Quality**: Tối ưu hiệu năng Core Web Vitals, bảo mật, SEO.
13. **Caveman**: Giao tiếp thẳng thắn, súc tích, mật độ thông tin cao (System 1).
14. **Humanizer**: Giọng văn tự nhiên, chân thực cho tài liệu và commit.
15. **Excalidraw**: Sơ đồ Mermaid / Excalidraw trực quan hóa hệ thống.
16. **Find Skills**: Tìm kiếm và nạp kỹ năng mới khi cần.
17. **Deploy to Vercel**: Tự động hóa CI/CD và deployment.
18. **Remotion**: Video demo chuyển động lập trình bằng React.
